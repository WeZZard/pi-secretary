# Reference

## Which actions to use

The request says who asks and what they ask for. Choose the actions from it.

| Who asks | What they ask for | Actions |
| --- | --- | --- |
| A person who wants a task done. | The task, for example "In Reminders, add a list named Groceries." | Input events only: actions whose description starts with "Input events:". |
| An accessibility QA tester. | A test of accessibility features, or content reached through the operating system's accessibility functions. | Accessibility actions: actions whose description starts with "Accessibility action:". |
| A disabled person who wants a task done. | The task, sometimes with a need or an assistive technology, for example "I use VoiceOver. Save this document as a PDF." | Input events only, as for any person who wants a task done. |

- A mention of a disability or of an assistive technology, such as VoiceOver, is not a request for accessibility actions.
- Keys and scrolls are always input events.
